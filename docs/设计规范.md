# DormLink 设计规范（Design System）

> 适用范围：DormLink 全部页面与组件。所有视觉数值必须来自 `entry/src/main/ets/common/DesignTokens.ets`，**禁止在页面中硬编码颜色、字号、间距、圆角**。
> 主题：浅色（Light），参考米家 App：浅灰底 + 白色大圆角卡片 + 橙色主色 + 设备网格。设备"开启"状态用橙色图标底与绿色状态徽章区分。

---

## 1. 设计原则

| 原则 | 具体做法 |
| --- | --- |
| **状态优先** | 用户关心"设备现在是什么状态"，因此设备卡的开关状态用高饱和色（成功绿/警示橙），其余信息一律降饱和 |
| **因果可见** | 改一个环境量 → 触发哪条规则 → 哪台设备变化，三者要在同一屏内形成视觉因果链：数值用强调色、规则 ID 用等宽感标签、设备卡紧跟结果摘要 |
| **层级靠字号与留白，不靠颜色堆叠** | 同一屏最多出现 2 种强调色；颜色只承担语义（成功/警告/危险/品牌），不承担装饰 |
| **一致性高于局部精致** | 页面标题一律左对齐、卡片一律 16px 内边距 + 1px 描边、按钮一律 44px 高，不为单页破例 |

## 2. 色彩系统

按**用途**命名而非色相，便于后续换肤。所有值定义在 `ColorToken`。

### 2.1 背景层级（由深到浅）

| Token | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F5F6F8` | 页面底色（浅灰） |
| `surfaceHigh` | `#FFFFFF` | 顶部栏 |
| `surface` | `#FFFFFF` | 卡片 |
| `surfaceAlt` | `#F0F2F5` | 输入框、嵌套块、关闭态图标底 |
| `overlay` | `#F5F6F8` | 全屏弹层底色 |

> 白色卡片放在浅灰底上，靠 1px 极浅描边（`#EDEFF2`）区分层级，不使用重阴影，保持米家式的干净感。

### 2.2 边框

| Token | 值 | 用途 |
| --- | --- | --- |
| `border` | `#EDEFF2` | 卡片常规描边、分隔线 |
| `borderStrong` | `#DDE1E7` | 需要强调的分隔 |

### 2.3 文字

| Token | 值 | 用途 | 对比度（对 `surface`） |
| --- | --- | --- | --- |
| `textPrimary` | `#1A1D21` | 标题、关键数值 | ≈ 15.8:1 |
| `textSecondary` | `#8A9099` | 正文、辅助说明 | ≈ 4.6:1 |
| `textTertiary` | `#B0B6BF` | 注释、占位、次要标签 | ≈ 3.1:1（仅用于 12px 以上的非关键信息） |
| `textInverse` | `#FFFFFF` | 橙色/绿色底上的文字 | — |

### 2.4 品牌与强调

| Token | 值 | 用途 |
| --- | --- | --- |
| `brand` | `#FF6900` | 主按钮底色、TabBar 选中、设备开启态（米家橙） |
| `brandPressed` | `#E55F00` | 主按钮按下态 |
| `accent` | `#FF6900` | 关键数值、滑块已选段 |
| `accentSubtle` | `#FFF1E8` | 开启态设备图标底 |

> **一屏一个主按钮**：主按钮用 `brand`，其余动作一律 `borderStrong`（次级）或纯文字（三级）。

### 2.5 状态色

| Token | 值 | 背景 Token | 用途 |
| --- | --- | --- | --- |
| `success` | `#00C48C` | `successBg` `#E6FAF4` | 设备「开」徽章、测试通过 |
| `warning` | `#FF9500` | `warningBg` `#FFF4E5` | 冲突提示、规则被拦截 |
| `danger` | `#FF3B30` | `dangerBg` `#FFECEB` | 删除、校验失败 |

> 状态色**只用于状态本身**：不要用 `danger` 做普通按钮底色，也不要用 `success` 做装饰。

## 3. 字体系统

字体族：系统默认（HarmonyOS Sans），代码片段用等宽。

| Token | 字号 | 用途 |
| --- | --- | --- |
| `display` | 19 | 页面主标题（顶部栏唯一一处） |
| `title` | 17 | 卡片标题、弹层标题、汇总数字 |
| `heading` | 15 | 区块标题、按钮文字 |
| `body` | 13 | 正文、条件/动作文案 |
| `label` | 12 | 标签、优先级等辅助信息 |
| `caption` | 11 | 说明文字、注释（最小可用字号） |

规则：
- 相邻层级至少差 2px，避免"看起来一样大"。
- 字重只用 `Regular(400)` 与 `Medium(500)`；标题用 Medium，正文一律 Regular。
- 行高：正文 1.5 倍，标题 1.3 倍。
- 一屏内标题不超过 3 种字号。

---

## 4. 间距与栅格

基准 4px，常用 8 的倍数。定义在 `SpaceToken`。

| Token | 值 | 用途 |
| --- | --- | --- |
| `xs` | 4 | 图标与文字、标签内边距 |
| `sm` | 8 | 紧密元素之间 |
| `md` | 12 | 卡片之间、列表项之间 |
| `lg` | 16 | 页面左右边距、卡片内边距 |
| `xl` | 20 | 大区块之间 |
| `xxl` | 28 | 页面首尾留白 |

布局规则：
- 页面左右边距固定 `lg`（16）。
- 卡片之间固定 `md`（12）。
- 卡片内边距固定 `lg`（16）。
- **滚动内容底部留 80px**，避免最后一张卡片被底部 tabBar 遮挡。

---

## 5. 圆角与描边

| Token | 值 | 用途 |
| --- | --- | --- |
| `sm` | 8 | 小标签、输入框内的小元素 |
| `md` | 12 | 嵌套块、小卡片、toast |
| `lg` | 18 | 主卡片（米家式大圆角） |
| `pill` | 999 | 按钮、状态标签、开关外框 |

- 描边统一 1px（`SizeToken.borderWidth`），颜色 `border`。
- 不使用阴影：深色背景下阴影不可见，层级靠"底色差 + 描边"表达。

## 6. 组件规范

### 6.1 按钮

| 类型 | 高度 | 圆角 | 底色 | 文字 | 使用场景 |
| --- | --- | --- | --- | --- | --- |
| Primary | 46 | pill | `brand` | `textInverse` 15 | 每屏唯一的主操作（执行演练、保存） |
| Secondary | 46 | pill | `surfaceAlt` | `textPrimary` 15 | 并列的次要操作（重置环境、取消） |
| Danger | 34 | pill | `dangerBg` | `danger` 13 | 删除、恢复出厂 |
| Text | 34 | — | 透明 | `accent` 13 | 卡片内的低权重操作（编辑） |

- 同一行最多 2 个按钮；两个按钮等宽时用 `layoutWeight(1)`。
- 按钮文字不加图标，保持一行。

### 6.2 卡片

- 底色 `surface`，圆角 `lg`，内边距 `lg`，1px `border` 描边。
- 卡片标题 `title` + Medium；正文 `body` + `textSecondary`。
- 卡片内不再嵌套第二层卡片；需要分区时用 `surfaceAlt` 的块，圆角 `md`。

### 6.2.1 设备卡（米家网格卡）

- 两列网格（`Flex` wrap，单卡宽 48%），卡间距 `md`。
- 卡内结构：左侧圆形图标底（44px，开启 `accentSubtle` 底 + `brand` 字，关闭 `surfaceAlt` 底 + `textTertiary` 字）→ 右上「开/关」徽章（开启 `success` 底白字，关闭 `surfaceAlt` 底灰字）→ 设备名 `title` → 状态 `caption`（开启 `success` 色）→ 开启时底部 3px 橙色进度条。
- 图标用**实物图形**（`dev_light` / `dev_ac` / `dev_curtain` / `dev_fan` / `dev_humidifier` 五张 PNG，统一深灰线条 + 橙色点缀），关闭态整体 `opacity(0.45)` 变淡。
- 图标资源位于 `entry/src/main/resources/base/media/`，由 `tools/gen_device_icons.py` 生成，改配色只需改该脚本重跑。

### 6.2.2 顶部栏（米家式）

- 左侧：家庭名（`display` 21px Medium）+ 下拉箭头（`label` 灰），下方一行环境摘要（`caption`，温度/湿度/光照）。
- 右侧：设备在线数（20px Medium，`brand` 橙色）+ 「设备在线」标签（`caption` 灰）。
- 底色 `surfaceHigh`（纯白），左右 `lg`、上 `lg`、下 `md`。
- 顶部栏不放存档提示等运维信息，这类信息归入日志页。

### 6.2.3 快捷场景卡（横向滚动）

- 容器 `Scroll` + `Row(space: md)`，`scrollable(ScrollDirection.Horizontal)`，隐藏滚动条。
- 单卡宽 116，内边距 `md`，圆角 `lg`，底色 `surface`。
- 卡内：40px 圆形图标底（`accentSubtle` 底 + `brand` 中文字：月/日/晨/夜）→ 场景名（`label`）→ 「S1 · 23 点」（`caption` 灰）。
- 点击直接载入该场景并演练，与演练页的完整场景卡复用同一份 `SCENE_PRESETS`。

### 6.2.4 设备详情页（米家式全屏控制）

- 进入方式：点击首页设备卡；全屏覆盖，底部无 TabBar。
- 结构（自上而下，卡片间距 `md`）：
  1. 顶部导航：左「‹ 返回」（`textSecondary`）、中设备名（`title`）、右侧留白占位保证标题居中。
  2. 设备主卡：88px 圆形图标底（开启 `accentSubtle`，内嵌 56px 实物图标；关闭 `surfaceAlt` + 图标 45% 透明度）→ 设备名 `title` → 状态 `caption`（开启 `success` 色）。
  3. 电源开关卡：左「电源开关」，右 `Toggle`（`selectedColor: brand`）。
  4. 参数卡：左参数名（空调=目标温度、窗帘=开合度、主灯=亮度、其余=档位），右数值 `brand` 色，下方 `Slider`（`selectedColor: brand`）。取值范围：空调 16–30℃、窗帘/主灯 0–100、风扇/加湿器 0–3 档。
  5. 定时卡：「不定时 / 30 分钟 / 1 小时」三个 pill，选中 `brand` 底白字，未选 `surfaceAlt` 底灰字。
  6. 设备信息卡：设备 ID、计量单位（`caption` 左右对齐）。
- 数据联动：修改开关或数值立即写入 `this.devices` 并持久化，返回首页后设备卡与"设备在线"数同步刷新。
- 定时为真实 `setTimeout` 实现，切换选项会先 `clearTimeout` 取消上一个定时。

### 6.2.5 底部 TabBar

- 高度 58，白底（`surfaceHigh`），顶部 1px 分隔线（`border`），`barMode: Fixed`。
- 每项：24px 线性图标（上）+ 文字 `caption`（下，间距 3）。
- **选中态**：橙色图标（`tab_*_on`）+ 橙色文字 + `Medium` 字重；未选中：灰色图标（`tab_*_off`，`#969EA8`）+ 灰色文字 + `Regular`。
- 图标为成对资源：`tab_home` / `tab_rule` / `tab_scene` / `tab_log` 各有 `_on`、`_off` 两张 PNG（48×48，线宽 3，圆头端点），由 `tools/gen_device_icons.py` 一并生成。
- 不使用字符符号（◉▤▶▦）做图标——不同字体下粗细和基线不一致。

### 6.3 状态标签（Tag）

- 圆角 pill，内边距 3/10，字号 `label`。
- 开启：`successBg` 底 + `success` 字；关闭：`border` 底 + `textTertiary` 字。
- 拦截：`warningBg` 底 + `warning` 字。

### 6.4 滑块（Slider）

- 轨道高 4px，轨道色 `border`，已选段 `accent`，滑块 20px 白色。
- 左侧标签 `body` + `textPrimary`，右侧数值 `body` + `accent`（数值是用户最关心的，用强调色）。
- 滑块与上方标签间距 `md`，与下一组间距 `lg`。

### 6.5 开关（Toggle）

- 开启 `brand`，关闭 `border`，尺寸保持系统默认。
- 与文字基线对齐，位于行尾。

### 6.6 输入框（TextInput / Select）

- 高 40，底色 `surfaceAlt`，圆角 `md`，无描边，文字 `body` + `textPrimary`。
- `Select` 必须同时设置 `.selected()` 与 `.value()`，否则只显示箭头（项目实际踩过的坑）。

### 6.7 Toast

- 位置：屏幕顶部距顶 104px，居中，宽度随内容。
- 成功 `success` 底 + `textInverse` 字；警告 `warning` 底；错误 `danger` 底。
- 圆角 `md`，内边距 14/10，字号 `body`。
- **必须渲染在 `Stack` 最上层**，否则会被全屏弹层（规则编辑器、测试报告）遮挡。

## 7. 页面结构

```
┌───────────────────────────────┐
│ HeaderBar  surfaceHigh        │  标题 display + 副标题 label + 状态行 caption
├───────────────────────────────┤
│ 内容区（Scroll）               │  左右 16，卡片间距 12，底部留白 80
│  区块标题 heading（左对齐）      │
│  卡片…                         │
├───────────────────────────────┤
│ TabBar 58                     │  联动台 / 规则 / 演练 / 日志
└───────────────────────────────┘
```

- 所有区块标题**左对齐**（不使用居中标题）。
- 顶部栏右侧状态信息右对齐，字号 `caption`，两行以内。
- TabBar 固定在底部，选中项用 `accent`，未选中 `textTertiary`。

## 8. 可访问性与校验清单

- 正文与背景对比度 ≥ 4.5:1，`textTertiary` 仅用于非关键信息。
- 可点击区域高度 ≥ 34px，主按钮 44px。
- 颜色不作为唯一信息载体：设备状态同时用文字（运行中/已关闭）+ 颜色表达；拦截记录同时用「已拦截」文字 + 橙色。
- 提交前自查：
  1. 页面内是否还有 `'#XXXXXX'` 硬编码颜色？（应为 0）
  2. 是否还有 `.fontSize(数字)` 硬编码？（应为 0）
  3. 卡片内边距是否统一 16？
  4. 滚动内容底部是否留了 80？
  5. toast 是否在最上层？

## 9. 落地方式

| 层 | 文件 | 说明 |
| --- | --- | --- |
| Token | `entry/src/main/ets/common/DesignTokens.ets` | `ColorToken` / `FontToken` / `SpaceToken` / `RadiusToken` / `SizeToken` |
| 页面 | `entry/src/main/ets/pages/Index.ets` | 全部引用 Token，已消除 124 处硬编码颜色、124 处硬编码字号/间距/圆角 |

校验命令（应无输出）：

```bash
grep -nE "'#[0-9A-Fa-f]{6}'" entry/src/main/ets/pages/Index.ets
grep -nE "\.fontSize\([0-9]+\)" entry/src/main/ets/pages/Index.ets
```

## 10. 演进方向

- 把重复出现的卡片 / 按钮 / 标签抽成 `@Component`（当前为 `@Builder`，参数为值传递，状态刷新需靠 `this` 读取，已在代码中注明）。
- 支持浅色主题：只需新增一套 `ColorToken` 并在 `EntryAbility` 中按系统主题切换，页面代码无需改动。
- 字号随系统字体缩放：将 `FontToken` 的固定值改为 `fp` 单位并接入系统字体大小。
