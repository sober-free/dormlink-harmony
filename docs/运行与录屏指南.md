### 执行过程中修复的三个真实缺陷

1. **@State 更新后界面不刷新**：`@Builder` 的值传递参数（`MetricSlider` 的 `value`、`DeviceCard(d)`）在状态变化后不会重建，`ForEach` 以 `d.id` 作 key 也会复用旧节点，导致重启后存档已恢复、界面却仍显示默认值。修复：改为在 `@Builder` 内直接读 `this.envValue(key)`，并把 `ForEach` 的 key 拼上 `power` / `value` / `priority` 等状态字段。
2. **规则编辑器下拉框空白**：`Select` 只设了 `.selected(index)` 未设 `.value(text)`，界面只显示箭头。修复：补 `.value(metricLabel / opLabel / deviceName)`。
3. **恢复提示被初始化回调覆盖**：Slider 与 Toggle 在回填时会触发 `onChange`，进而调用保存逻辑，把「已从 Preferences 恢复…」覆盖成「本次改动已写入…」。修复：回调中先比较新值与原值，相同则直接返回。

## 1. 导入与编译

1. DevEco Studio → `File > Open` → 选择 `dormlink-harmony` 根目录。
2. 等待 `Sync` 完成；若提示 `ohpm install`，允许执行。
3. 若提示签名错误：`File > Project Structure > Project > Signing Configs`，勾选 `Automatically generate signature` 后重新 Sync。
4. 若 SDK 版本不匹配：把根 `build-profile.json5` 里的 `compatibleSdkVersion` / `targetSdkVersion` 改为本机已安装的 API 版本（如 `4.1.0(11)`）。
5. 选择 HarmonyOS 模拟器或真机，点击 `Run 'entry'`。
6. 首次启动应看到 6 条默认规则、5 个设备（全部 OFF）、顶部提示"未检测到有效存档，已加载默认方案"。

## 2. 运行 ohosTest 单元测试

1. 在 Project 视图展开 `entry/src/ohosTest/ets/test`。
2. 右键 `List.test.ets` 或 `ohosTest` 目录 → `Run 'Tests in entry'`。
3. 选择模拟器/真机，等待 14 条用例执行完毕，截图保存 **Run 面板的通过结果**（`14 tests passed`）。
4. 也可在终端运行纯逻辑测试作为交叉验证：
   ```bash
   node --test tests/node/rule-engine.test.mjs
   ```
   需要 Node.js ≥ 22.6，输出应与 `docs/测试运行日志.md` 一致（19/19 通过）。

## 4. 录屏分镜脚本（约 2 分 45 秒，一镜到底）

| 时间 | 画面 | 口播/字幕要点 |

| 0:32–0:52 | 切到规则页，展开 R001 | "双条件规则：时段≥22 且 在室=有人，两个条件必须同时满足" |
| 0:52–1:18 | 点「+ 新增规则」，配置一个双条件规则并保存 | "规则支持新增、编辑、启停、优先级；保存前做合法性校验" |
| 1:18–1:42 | 演练页载入 **S2 午后无人·冲突** | "31℃ 且无人：R002 想开空调，R005 想关空调；按优先级 R002 胜出，R005 的空调动作被拦截" |
| 1:42–2:00 | 点「一键修复」→ 重新演练 | "为 R002 补充『在室=有人』条件后，无人场景不再命中，冲突归零" |
| 2:00–2:18 | 日志页，逐条看执行记录 | "每条记录含执行序号、触发条件快照、设备变化前后值、是否被拦截" |
| 2:18–2:45 | 修改一条规则优先级 → **强制结束应用进程** → 重新启动 | "全部数据用 Preferences 落盘；重启后规则、设备状态与执行记录完整恢复" |

录屏要点：
- 全程录进顶部状态条（存档时间 / "已恢复存档"标记），这是持久化证据的关键。
- 结束进程请用系统「最近任务 → 上滑关闭」或 DevEco 的 `Stop`，不要只按 Home 键（后台保留不等于进程重启）。
- 重启后先停 2 秒再操作，让"已从 Preferences 恢复…"提示清晰可读。

## 5. 常见问题

| 现象 | 处理 |
| --- | --- |
| 编译报 SDK 版本错误 | 修改根 `build-profile.json5` 的 SDK 版本后 Sync |
| 编译报签名缺失 | 开启自动签名 |
| `node --test` 报 `Unknown file extension ".ts"` | Node 版本过低，升级到 ≥ 22.6 |
| 重启后没有恢复提示 | 确认是"强制结束进程"而非切后台；检查日志页告警是否有"存档写入失败" |
| 规则编辑保存时提示"规则不合法" | 检查是否删除了全部条件/动作，或阈值输入框为空 |
